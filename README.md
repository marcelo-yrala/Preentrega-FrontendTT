# Garras y Patitas - Refugio de Perros y Gatos

Sitio web del refugio **Garras y Patitas**, un espacio dedicado a rescatar, cuidar y encontrar hogares responsables para perros y gatos en situación de abandono.

## Propósito

El objetivo de la página es dar a conocer el refugio, mostrar los animales disponibles para adopción, ofrecer formas de colaborar (donaciones, voluntariado) y recaudar fondos mediante una **tienda solidaria de productos**, donde el 100% de lo recaudado se destina al alimento y la atención veterinaria de los peludos.

## Páginas

- `index.html` — Inicio: animales en adopción, productos solidarios y reseñas.
- `adoptar.html` — Proceso y requisitos de adopción + formulario.
- `ayudar.html` — Formas de colaborar (donaciones, voluntariado, eventos).
- `nosotros.html` — Información del refugio, misión, visión y equipo.
- `contacto.html` — Formulario de contacto (enviado con Formspree) y ubicación.

## Tecnologías

- HTML5 con etiquetas semánticas (`header`, `nav`, `main`, `section`, `footer`).
- CSS3 externo (Flexbox, Grid y Media Queries) en `css/estilos.css` y `css/responsive.css`.
- Google Fonts (Outfit y Sour Gummy).
- Bootstrap 5 y Font Awesome (íconos).
- JavaScript para precargar el producto seleccionado en el formulario de contacto.
- Formspree para el envío del formulario de contacto.
